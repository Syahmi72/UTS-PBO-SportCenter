# UTS PBO - Sport Center Kampus (Reservasi Lapangan)

## Deskripsi Proyek
Sistem ini dirancang untuk mengelola reservasi lapangan olahraga di kampus
menggunakan paradigma Object-Oriented Programming (OOP) dengan bahasa Kotlin.

## Tema
Sport Center Kampus - Reservasi Lapangan

## Entitas Sistem

- Resepsionis: admin yang mengelola lapangan dan member
- Lapangan   : objek yang bisa dipesan oleh member

## Aturan Bisnis
- Member tidak bisa booking jika jadwal lapangan sudah penuh
- Booking hanya sah jika saldo Member mencukupi harga sewa
